# Employee Management System — Attendance, Leave & Role UI

Frontend overlay package for the existing React/Vite Employee Management System.

Includes:
- Attendance UI
- Leave Management UI
- Leave approval/rejection UI
- Role administration UI
- Reusable role-based visibility component
- Responsive, clean HR/admin styling
- API service modules
- Integration documentation

This is an overlay package, not a replacement for the complete project.
Copy the files into the existing project and follow `docs/ATTENDANCE_LEAVE_ROLES_SETUP.md`.
